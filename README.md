# **Sistema de Boletines Preescolar**
 
📌 **Descripción**
Proyecto desarrollado en Python aplicando los conceptos fundamentales de Programación Orientada a Objetos (POO). El sistema permite gestionar estudiantes, acudientes y profesores, registrar áreas con notas, observaciones y generar boletines académicos con cálculo de desempeño.

⚙️ **Tecnologías**
Python

📁 **Estructura del proyecto**

clases/

persona.py
estudiante.py
acudiente.py
profesor.py
area.py
boletin.py
excepciones.py

main.py
README.md

🚀 **Cómo ejecutar**

Abrir la terminal

Ubicarse en la carpeta del proyecto

Ejecutar:

python main.py

🧠 **Conceptos aplicados**
* Clases, objetos y métodos
* Encapsulación (atributos privados)
* Constructores (_init_)
* Herencia (Persona → Estudiante / Acudiente / Profesor)
* Sobreescritura de métodos
* Polimorfismo
* Abstracción (clases abstractas con ABC)
* Interfaces (uso de clases abstractas)
* Composición entre clases
* Manejo de excepciones

✨ **Funcionalidades**
* Registro de estudiantes
* Registro de acudientes
* Registro de profesores
* Creación de boletines académicos
* Ingreso de áreas y notas (rúbricas)
* Validación de notas (0 a 5)
* Cálculo de promedio
* Determinación de desempeño
* Generación de boletín formateado
